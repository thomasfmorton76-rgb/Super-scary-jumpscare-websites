# 😱 Awesome Jumpscare Websites

A curated list of infamous, interactive, and classic jump scare websites across the internet. 

> **⚠️ WARNING:** The websites listed in this repository contain **sudden loud noises, flashing lights, and startling imagery**. Proceed with caution and lower your volume. Do not visit if you have photosensitive epilepsy, heart conditions, or anxiety.

---

## 🕸️ Classic & Viral Jump Scare Sites

* **[Staggering Beauty](http://staggeringbeauty.com)** – Features an interactive black worm that follows your cursor. If you shake the mouse too vigorously, the screen erupts into intense flashing colors and loud screeching noises. *(Extreme flashing light warning).*
* **[The Maze (Scary Maze Game)](https://playscarymazegame.net)** – The legendary Flash-era prank game where you guide a dot through increasingly narrow walls until Level 3 triggers a sudden, loud scream and horror face.
* **[Lomando.com (Fancy Island)](https://lomando.com)** – A seemingly cute Japanese browser game styled like a bright pop-art website that quickly devolves into a labyrinth of point-and-click horror puzzles and sudden scares.
* **[Find the Invisible Cow](https://findtheinvisiblecow.com)** – While mostly harmless fun (you locate a hidden cow by listening to louder "moos"), the sudden transition to a loud celebration screen can catch unsuspecting players off guard.
* **[Anne.jpg](https://archive.org)** *(Archived)* – A notorious shock site from the early 2010s that hijacked browser windows with a violently shaking, screaming face.

## 🛠️ Open-Source GitHub Jump Scare Templates

If you want to host your own harmless prank page for friends, check out these existing open-source repositories:

* **[makoryne/jumpscare](https://github.com/makoryne/jumpscare)** – A lightweight HTML/CSS/JS template that displays an innocent landing page before triggering a custom image and scream audio.
* **[ReemanS/simple-js](https://github.com/ReemanS/simple-js)** – A minimal web template disguised as an ordinary page that triggers a jump scare upon clicking a specific button.
* **[ilhamjaya08/pr4nk.me](https://github.com)** – A TypeScript-based prank platform featuring fake updates, fake screens, and jump scare modules.

## 🛡️ Helpful Tools

* **[NotScare.me](https://notscare.me)** – A community-driven database that lets you look up exact timestamps and intensity ratings for jump scares in horror movies, TV shows, and video games before watching or playing.
